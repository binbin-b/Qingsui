# 轻随 · Qingsui

用聊天记录内容，用待办、日期和标签整理事情。原生 macOS 应用，资料保存在你指定的本地文件夹。

## 下载与安装

在 [Releases](https://github.com/binbin-b/Qingsui/releases) 下载 `Qingsui-0.7.2-macOS-arm64.dmg`，打开后将轻随拖到 Applications。

- 支持 **Apple Silicon（M 系列）Mac、macOS 14+**；目前没有 Intel、Windows、手机和平板安装包。
- 当前为 **0.7.2 测试版**，仅本机 ad-hoc 签名，尚未取得 Developer ID 签名及 Apple 公证。首次打开可能被 macOS 拦截，请核实下载来源与校验值，并阅读 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。
- 可用 `shasum -a 256 下载的文件.dmg` 对照 Release 的 `SHA256SUMS.txt` 检查下载文件。
- 安装包不包含个人记录。首次启动选择本地资料库文件夹；升级前建议先备份。

## 主要功能

- 发送文字、图片、文件和链接，Enter 发送、Shift Enter 换行；多图叠放、文件卡片、长消息折叠和独立阅读。
- `@` 选择或创建待办；一条消息最多关联一个待办，多条消息可共同关联同一事项。
- 日期选择器或 `/月日` 安排今天起一年内的事情，选日期后直接写内容即可自动创建待办。
- 双击消息完成，绿色变灰；支持撤销、置顶、撤回编辑、删除恢复和部分／跨气泡选字复制。
- 标签合集、搜索和消息多选，统一关联待办、共同日期或共同标签。
- 桌面悬浮球管理待办并快速记事；侧边窄条始终保留输入区，主窗口不再自动置顶。
- 液态玻璃外观、日夜模式、四种可选悬浮球样式及可修改的应用内快捷键。
- 待办／标签合集可从左侧或气泡中的名称进入，后续消息自动关联，支持退出合集。
- 可选复制反馈：剪贴板更新后播放默认彩带、1～5 个 Mac 表情或简洁提示，不读取或保存复制内容。
- 一键完整备份与可阅读格式导出。

具体操作见 [使用说明](使用说明.md)，APP 右上角及帮助菜单也可随时打开。

## 数据与恢复

资料库由 `ChatLedger.library.json` 和 `Attachments/` 等文件组成，不会自动上传到服务器。

**备份**生成包含消息、待办、标签、已删除记录和附件的 ZIP；恢复时解压，再在 APP 中选择里面的资料库文件夹。
**导出**生成 Markdown 记录、CSV 待办、JSON 消息及附件，排除已删除／撤回消息，不受当前筛选影响；导出不替代完整备份。

当前数据格式为 v4，首次修改旧资料库前自动留下升级前备份。不要让多个应用同时修改同一资料库。网盘共享文件夹不等于可靠实时同步：当前没有外部修改监听、冲突合并或跨设备同步。

## 从源码构建

在 macOS 安装 Xcode 或 Command Line Tools，Swift 5.9+。没有第三方 Swift 包依赖。

```sh
zsh test.sh
zsh test-layout.sh
zsh test-floating.sh
zsh test-selection.sh
zsh test-copy-feedback.sh
zsh build.sh
```

`build.sh` 生成 `dist/轻随.app`；`zsh scripts/package-release.sh` 生成 DMG、ZIP 与 SHA256 校验文件。
`build-dev.sh` 构建独立标识的开发版。

## 当前限制

应用快捷键仅在前台生效；搜索不读取附件内部内容。到期提醒需要应用保持运行；没有系统全局快捷键、云同步或内容加密。macOS 26 使用原生液态玻璃，macOS 14–15 使用磨砂兼容外观。

23 项数据测试及输入布局、文字选择、悬浮球和窗口层级回归已通过。复制反馈的检测时序、表情保存和浮层属性测试通过；全局功能默认关闭，需辅助功能权限，授权后的跨 App 行为尚未完整实测。尚未覆盖所有输入法、多显示器和长期运行组合。
