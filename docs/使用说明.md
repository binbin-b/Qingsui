# 轻随使用说明

- **记录**：像聊天一样发送文字、图片、文件和链接。Enter 发送，Shift Enter 换行，附件拖入或粘贴。
- **待办**：输入 `@标题`，用 Enter／Tab 选择或新建；一条消息最多一个待办。同一事项可关联多条消息，全部完成才完成待办。点击左侧待办或气泡内的 @待办名称进入后，新消息自动关联它；点“退出待办”恢复普通记录。
- **日期**：点击日历图标选日期，再写事情即可自动成为待办。也可输入 `/1113` 确认 11 月 13 日，日期从今天起一年内自动匹配。
- **完成**：双击气泡，绿色变灰；右键可撤销。勾选清单中的待办会完成全部关联消息。
- **标签合集**：输入 `#` 选择已有标签，`# ` 在标签框内创建，Tab 切换、Enter 确认。点击左侧标签或气泡内的 #标签进入合集后，新消息自动继承该标签，点“退出标签”结束。
- **批量关联**：右键消息选“多选”，勾选多条后点“关联…”。一次可关联一个共同待办、日期或标签；原有标签保留。
- **筛选与搜索**：点击待办、日期、标签查看相关消息；放大镜搜索正文、待办、标签和文件名。右键标签可以隐藏该标签内容。
- **长文与图片**：点“展开阅读”独立阅读全文；图片点开后用左右箭头切换。拖选文字按 ⌘C，可选取部分文字或跨气泡复制。
- **消息管理**：右键可置顶、删除、撤回；撤回后可重新编辑，删除后可从文件夹菜单恢复。
- **悬浮球**：单击或停留展开待办，按住拖动，双击清单空白处收起。底部“快速记事”Enter 发送到主页面，不加入待办。
- **窄条与设置**：右上角侧边按钮收起／展开，始终保留输入框；主窗口不会自动置顶。齿轮内可切换日夜模式、修改快捷键，并在“主题”里选择四款悬浮球。
- **备份与导出**：左下角或“资料库”菜单操作。备份用于完整恢复，导出用于阅读及表格处理。

默认快捷键（仅应用前台生效，可在设置修改）：

| 操作 | 快捷键 |
| --- | --- |
| 收起／展开页面 | ⇧⌘M |
| 展开悬浮待办 | ⇧⌘T |
| 新建待办 | ⇧⌘N |
| 新建记事 | ⇧⌘J |
| 搜索 | ⌘F |
| 设置 | ⌘, |
| 使用说明 | ⇧⌘H |

- **复制反馈**：设置中开启后，⌘C 加剪贴板更新触发左下角小礼花。可选默认彩带或 1～5 个 Mac 表情，点笑脸打开表情面板，保存后预览；也可改为简洁提示。要在其他 App 生效需启用全局并自行授予辅助功能权限，轻随需保持运行。只检测剪贴板变化，不读取、保存或上传内容。
