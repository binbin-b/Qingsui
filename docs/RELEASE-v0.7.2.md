轻随 Qingsui 0.7.2 公开测试版，本次包含 0.7.1 的本地优化。

- 新增复制反馈：检测 ⌘C 后的剪贴板更新，播放小礼花或简洁提示；礼花支持默认彩带、1～5 个 Mac 表情及效果预览。
- 待办合集内发送消息自动关联当前待办；点击左侧列表或气泡里的 #标签、@待办名称均可进入合集，并可一键退出。
- 修复主窗口在窄条模式下自动置顶的问题。
- 主题中新增青绿圆环、蜡笔青苹果、纯净玻璃悬浮球，保留原 Logo 样式。
- 同步更新使用说明。

**安装**：M 系列 Mac、macOS 14+。下载 DMG，拖入 Applications；ZIP 为备用格式，SHA256SUMS.txt 提供校验值。升级前建议备份，再选择原资料库文件夹。

**说明**：复制反馈默认关闭；全局生效需自行授予辅助功能权限，授权后的跨 App 效果尚待完整实测。本版仍未取得 Apple Developer ID 签名和公证，首次打开可能被 macOS 拦截，见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。
