轻随 Qingsui 首个 GitHub 公开测试版。

### 下载安装

- Apple Silicon（M 系列）Mac，macOS 14 或更新版本。
- 下载 **Qingsui-0.7.0-macOS-arm64.dmg**，打开并将轻随拖入 Applications；ZIP 为备用格式。
- `SHA256SUMS.txt` 提供两个下载文件的校验值。
- 本版本尚无 Developer ID 签名与 Apple 公证，macOS 可能拦截首次启动。请核实来源，并阅读 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

### 功能

聊天记录文字、图片、文件与链接；待办、日期、标签合集与搜索；多选统一关联；长消息独立阅读；桌面悬浮待办和快速记事；侧边窄条；液态玻璃与日夜模式；可修改快捷键；完整备份与导出。

### 数据

安装包不包含个人消息。首次启动选择本地文件夹；已有用户升级前请先备份，继续选择原资料库即可。不要同时运行两个版本修改同一资料库。目前不支持云端冲突合并，应用内快捷键只在前台生效。

22 项数据测试、编辑区布局、跨气泡文字选择及悬浮球交互回归通过。完整用法见仓库使用说明和 APP 帮助入口。
